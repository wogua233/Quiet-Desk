# 0.4.2 阅读列表日期修复

日期：2026-09-14。

## 原因与修复
0.4.1默认仅显示当天发表的文章，导致已收录的非日更期刊被筛选隐藏。
本轮在相同网络实测，仅BBC、Guardian和Nature Communications有当天条目，与用户描述吻合。
默认改为最近7天（含当日），明确显示实际日期范围；单日、发现日期、收藏与未读筛选仍可选择。
日期未知的条目在最近7天中按发现日期纳入，显示“日期待确认”，不伪装为当天发表。
空列表说明来源是否失败，并显示已收录的最新发表日期。
Nature官方RSS的content:encoded确实承载简短导读，现按该来源专门提取并去掉发表日期／DOI头部，标记“基于导读”。其他来源不会因此导入全文content。
升级后内置解析版本变更触发一次非条件请求，避免旧缓存304阻止Nature导读修复；以后继续条件更新。
