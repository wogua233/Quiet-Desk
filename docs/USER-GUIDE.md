# 静隅 0.3 / Quiet Desk

面向 Windows 11 x64 的轻量专注音乐播放器。WPF 原生界面，中性石墨深色与柔粉强调，真正嵌入桌面的窄卡片。

## 启动与日常使用

解压 `QuietDesk-win-x64.zip`，运行 **QuietDesk.exe**。保留同目录的 DLL、Assets 与许可文件；自包含发布包不需要另外安装 .NET。启动保持暂停，默认不开机启动。

- **声音场景**：18 种声音全部离线，按自然、空间、噪声分类；支持搜索和只查看已启用声音。最多混合四路，达到上限时可明确选择替换。
- **声音组合**：保存、恢复、更新与重命名；同名覆盖需要确认，删除可撤销。恢复场景保持当前播放/暂停状态。
- **在线电台**：内置“国内直连”目录不依赖海外查询，另提供 Radio Browser 搜索、分类、收藏。支持 HTTP(S) MP3、HLS/AAC 音频直链；断网不影响环境声。目录显示实际测试与直连待验证说明，网页地址不是直播地址。
- **独立暂停**：底部“全部暂停／恢复”控制整体；“暂停电台／音乐”只影响媒体。单独暂停后，总恢复不会擅自恢复它。直播继续时重新连接当前位置，本地音乐保留位置。
- **输出设备**：设置中选择“跟随系统默认”或具体设备，所有声音和轻音效使用同一选择；设备失效回退默认并提示，保持暂停状态。
- **本地队列**：导入 MP3/WAV/FLAC，上一首、下一首、循环、拖动名称排序。文件丢失时可定位替换或移除；移除不删除音乐文件。
- **音量**：百分比显示；静音后可恢复之前的音量。滑块方向键每次调整 1%，滚轮仅在滑块获得键盘焦点后调音量。
- **专注**：默认 25 分钟，可设 1–240 分钟，暂停后继续。修改进行中的时长会先确认重置。结束不响铃、不弹窗、不自动下一轮；系统睡眠后计时保持暂停。
- **轻音效**：设置中可选，默认关闭，独立音量并遵守总静音；主动试听在全部暂停时也可使用，悬停、音量拖动、后台事件和计时结束无音效。

关闭主窗口会收起。双击系统托盘的叶片图标恢复，托盘菜单提供播放、专注与退出。

桌面卡片空白处拖动；按钮和滑块静止按住约 250 毫秒后可拖整卡，滑块立即拖动仍调音量。靠近左右边缘吸附，离开约 800 毫秒后收为 8 DIP 把手，悬停约 250 毫秒展开；可锁定位置。背景默认 88% 不透明，设置可调；不支持透明合成时使用不透明渐变。“调整混音”仅展开已启用的最多四路，“选择更多声音”打开主窗口。

窗口内快捷键：`Ctrl+空格` 播放/暂停，`Ctrl+1…4` 切换页面，`Ctrl+Shift+Q` 退出。

## 声音与许可

细雨、溪流、海浪、微风、森林、炉火、窗边雨、远雷、夏夜虫鸣、树叶沙沙、白噪声、粉红噪声、棕噪声、咖啡馆、图书馆、列车、风扇、轻键盘声。

录音做了首尾交叉淡化及响度处理。白/粉红/棕噪声为项目生成；窗边雨是雨声素材的隔窗听感处理版。图书馆是阅览室底声，咖啡馆使用餐厅背景录音。素材时长如实记录，不把重复延长称为新录音。

**图书馆录音采用 CC BY-NC 4.0，仅限非商业使用。** 其余各声音同样按自己的许可分发，详见 [完整声音许可](SOUND-LICENSES.md)。HLS/AAC 随包解码器及源代码、固定版本校验见 [FFmpeg 说明](FFMPEG.md)。NAudio 与 .NET 许可在 `licenses` 或 `docs/licenses`。本软件不打包、不录制在线电台节目。

## 数据与兼容

所有数据保存在 `%LOCALAPPDATA%/QuietDesk/`：`state.json` 保存组合、收藏、队列、音量与每日专注时长，`placement.json` 保存桌面位置，`radio-cache.json` 保存最近查询缓存。诊断日志有大小上限。

兼容 0.1 / 0.2 的数据，新增轻音效默认关闭。设置原子替换；损坏文件保留副本。不需要账号，无云同步和自动更新。

## 构建与复现

使用 Windows x64 与 .NET SDK 10.0.401：

```powershell
./scripts/build.ps1
./scripts/build.ps1 -Publish
./scripts/package.ps1
```

当前工作区 SDK 位于 `.tools/dotnet`；其他环境通过 PATH 查找 dotnet。源码附已生成的 WAV 和矢量图标代码，正常构建不需要 Python。若需重制录音：

```powershell
./scripts/download-sounds.ps1
./scripts/download-expanded-sounds.ps1
python scripts/prepare-sounds.py
python scripts/prepare-expanded-sounds.py
```

需要 numpy、scipy、soundfile；下载脚本验证源文件 SHA256，来源变更会中止。声音处理与输出校验见 `docs/sound-validation*.json`。

发布程序提供独立测试模式：

```powershell
./QuietDesk.exe --verify --out verification.txt
./QuietDesk.exe --radio-test --out radio-verification.json
./QuietDesk.exe --acceptance-run --channels 1 --seconds 600 --out single.json
./QuietDesk.exe --acceptance-run --channels 4 --seconds 600 --out four.json
```

完整应用验收模式使用独立临时设置，主窗口创建后隐藏，保留桌面组件，静音实际读取/混音/WASAPI 输出；另加 60 秒预热，测试结束自动退出。正常使用不写性能采样。测试期间的实际交互需在报告中保留说明。
