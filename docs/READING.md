# 阅读使用说明 · 0.4.1

按 Ctrl+5 打开阅读，首次选择“启用阅读并选择刊物”。默认不订阅任何来源，不会出声或弹出后台通知。

## 文章
选择日期、刊物，以及“按发表日期／按发现日期”。收藏筛选显示全部日期的收藏，未读筛选可组合使用。
左侧单击文章，右侧直接阅读中文总结和原始摘要；窗口较窄时切换为单页，使用“返回列表”。返回与页面切换保留选择和列表滚动位置。
正文可选择、复制；原始摘要可展开。收藏、原文入口和生成按钮直接可见，不再弹出独立阅读窗口。
日期可直接输入 yyyy-MM-dd 后回车，也可使用前一天／后一天／今天按钮。
未生成中文标题时显示原始标题。选中文章时可轻量补充公开摘要，不需要配置API；来源拒绝访问仍可能导致摘要不可用。

## 订阅
搜索刊物并勾选，或展开自定义 RSS／Atom。刷新后查看每个来源的成功时间、条目数与错误。
来源数和返回条目数不表示当天发表数；没有文章与连接失败分别显示。首次只收集最近七天可取得的记录。

## 总结与用量
右上角阅读设置配置兼容 Chat Completions 的 HTTPS 地址、模型和密钥。密钥在本机按当前Windows用户加密。
开启自动生成前确认发送标题和摘要／导读；默认每天10篇，可在1–500内调整。原有自动开关保留，升级不会擅自开启。
按订阅来源轮流处理当天文章；手动生成不占自动额度，会确认额外服务用量。自动额度按请求次数计费保护，失败请求也可能占用额度。
已有总结直接复用，升级不会批量重新请求。未配置API可阅读原始摘要和打开原文。
总结标注“基于摘要”或“基于导读”。来源资料不足时不根据标题编造，不获取全文、不导入或解析PDF。

## 兼容与低占用
升级首次将默认额度调整到10，之后保留用户修改；订阅、收藏、已读、密钥、已有短总结以及音乐设置保留。
旧全文任务取消，旧精读结果不再展示，仅清理应用自己的临时缓存，不删除原始PDF。
来源两小时增量检查，最多两路来源请求，摘要服务单路请求；未启用阅读不创建数据库或网络调度。
普通文章保留90天，收藏长期保留。关闭阅读页面释放列表与正文控件；不再运行全文进程或闲置检测。
