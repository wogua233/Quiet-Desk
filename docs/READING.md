# 阅读模块使用说明

在左侧进入“阅读”（也可按 Ctrl+5），选择“启用阅读”，然后到“订阅”勾选刊物。默认没有任何订阅，不配置 API 也能浏览目录、查看原始摘要和打开原文。

## 每日阅读

“今日”默认按发表日期筛选；勾选“按发现日期”可找迟到记录及发表日期不明的内容。可选择日期与刊物。列表每页最多200篇，并使用虚拟化控件；双击或“阅读摘要”打开详情并标记已读。

“更多操作”包含收藏、原文、精读、PDF导入、立即处理和取消精读。收藏页不受日期筛选限制。首次订阅仅收集最近七天在源中可取得的记录，RSS不保证完整历史。

## 配置摘要 API

在“阅读设置”输入兼容 Chat Completions 的 HTTPS 地址（例如服务提供商给出的 `/v1` 地址）、模型名称和密钥，保存并测试连接。未预置任何收费服务。密钥使用 Windows 当前用户 DPAPI 加密；不要将密钥写在 URL 或自定义订阅地址中。密钥框留空会保留已有密钥。

首次保存服务时确认摘要发送范围；只有勾选自动摘要后，系统才自动生成，每日默认50篇，按刊物轮流处理，手动生成不受此篇数限制且可能额外计费。自动额度在发出请求前记录，失败请求也消耗一次额度，避免不断重试产生费用。模型/API不兼容、额度不足或限流会显示错误，不影响音乐。

短总结基于摘要或导读，不等于已阅读全文。原始资料不足时不会只凭标题生成总结。全文精读首次另外确认发送范围，更换服务地址需要重新确认。

## 全文与机构权限

普通请求使用本机系统代理及网络，适用于机构IP授权。程序不读取浏览器登录Cookie，也不自动登录。页面需要登录、验证码或拒绝请求时，使用“打开原文”；能在浏览器阅读不代表程序也能读取。

可导入已合法取得的本地PDF：单份最多25MB，要求存在可提取文本。加密或扫描文档可能无法处理，首版不做OCR。原始PDF不会修改或删除。

精读按章节或页码组织文本并分段调用云端服务，可能比短摘要产生更多请求。PDF提取会标记是否完整；网页无法保证完整性时明确显示“完整性未确认”。目前不识别图表、图中文字或复杂公式结构。

## 后台与数据

- 订阅检查周期两小时，最多两路下载，使用条件请求和失败退避。断网保留已有数据；不驻留于应用退出后，不唤醒电脑。
- 全文任务单路执行。默认连续闲置三分钟、CPU低负载至少三十秒、接通电源且无全屏/演示时启动。用户恢复操作后取消后台解析；可用“立即处理”覆盖闲置等待。
- 全文解析在低优先级子进程中进行，私有内存限制256MB，最多运行90秒，结束后退出。云端请求串行。
- 阅读设置位于原数据目录的 `reading-settings.json`；文章、订阅和任务位于 `reading/reading.db`。普通文章保留90天，收藏保留。全文临时文件结束后清理；缓存清理上限200MB。
- “停用阅读后台”会停止服务并保留数据。再次启用可恢复订阅；尚未启用时不创建阅读数据库或后台队列。
