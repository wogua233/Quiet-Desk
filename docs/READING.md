# 阅读使用说明 · 0.5.3

按 Ctrl+5 打开阅读，首次选择“启用阅读并选择刊物”。默认只订阅 JACS，可以在“订阅”勾选其他来源。没有配置 AI 时也能阅读原始摘要；不播放通知声。

订阅页的“仅刷新订阅”只检查已勾选来源，不调用 AI。每个刊物旁的“重新检查”可检查该刊物，即使未订阅也可使用，不改变勾选状态。手动检查可跳过来源失败等待期；自动检查仍遵循退避。

来源状态保存最近一次实际检查结果，不会因升级软件、切换页面或外部测试成功而自动清空。检查成功（包括 HTTP 304、内容无更新）会替换旧失败；未订阅时明确显示“不自动检查”，订阅中的失败来源显示重试时间。已有文章保留。

## 双语文章

列表优先显示中文标题，下方保留英文原题；未翻译条目标为“待翻译”。右侧依次为中文摘要／导读译文、英文原文、中文总结。正文可选择和复制，三个部分分别标明资料范围。摘要不足时只能翻译标题，不会编造总结。

默认显示“订阅刊物”最近7天内容，按时间从新到旧。点击顶部“近7天 · 筛选”打开浮层，可选择日期、发表／发现日期、期刊名排序、时间升降序、收藏和未读；点击“应用筛选”生效，取消、Esc 或点击外侧放弃本次修改。日期未知使用发现日纳入最近7天范围，并保留未知标记。取消订阅不删除历史记录，点击刊物按钮选择“全部刊物”或该刊物仍可回看。

顶部工具栏使用紧凑按钮，窄窗口允许换行。底部仅保留一行阅读状态，悬停可查看完整信息；“AI队列”菜单集中提供立即开始、暂停队列及用量。阅读时音乐控制栏隐藏，切换到声音、电台等页面自动恢复，不改变播放状态；仍可通过桌面组件、托盘或主窗口 Ctrl+空格控制全部播放。

窗口较窄时显示列表或正文，使用“返回列表”恢复原位置。列表使用虚拟化，每页最多200条；筛选排序先于分页。

## AI 配置和操作

右上角齿轮进入阅读设置，配置 HTTPS 服务地址、模型和密钥。DeepSeek 地址建议 `https://api.deepseek.com`，Flash 模型名称须通过“测试连接”返回的模型目录确认。测试连接只读取模型列表，不发送生成请求；模型名称仍可修改。默认建议为 `deepseek-flash`，请求显式关闭 DeepSeek thinking。

密钥按当前 Windows 用户加密，不能直接复制加密配置供另一个 Windows 用户使用。首次保存服务地址会说明标题与摘要的发送范围，更换地址重新确认。自动处理默认关闭；已有用户的自动开关保持不变。

- **刷新**（悬停说明“刷新并翻译总结”）：先更新已订阅来源，再处理近7天全部待完成条目；没有 AI 配置时仍可刷新来源，配置后可能产生服务费用。
- **AI队列 → 立即开始**：处理已入库、近7天订阅文章，手动模式不要求电脑空闲。
- **AI队列 → 暂停队列**：不派发下一篇，已发出的请求完成后保存，避免取消重发造成额外费用。点击“立即开始”可继续。
- **翻译并总结／补齐／重试**：处理单篇选中文章，不受7天和订阅范围限制。操作前提示服务用量，完整缓存不重复请求。

本版取消每日10篇限制，自动范围是近7天所有订阅待完成文章，篇数可能较多。界面显示队列数量和本批请求、输入、输出与缓存命中 token；服务未报告的用量标为未知，不能当成零费用。联网中断或超时不盲目重发；明确限流会全队列退避，每篇最多3次，仍失败可手动检查后重试。

## 每日空闲调度

启用自动处理后，可选择“每天空闲时”或“每天指定时刻后空闲时”。后者必须填写本地 HH:mm，不预设任意时间。连续3分钟无键鼠操作、CPU低于20%持续30秒、未启用节电且无全屏／演示状态才派发自动任务。

用户恢复操作后停止派发下一篇，已发出的请求正常完成。音乐播放不会被当成键鼠忙碌。手动开始可以在工作时执行，但始终单路云端请求。

当天批次和队列持久化。重启继续未完成的自动队列；当天完成后新发现的文章等待次日或手动刷新。退出中断的请求会标为失败，不自动重复可能已收费的请求。程序退出后不驻留、不唤醒电脑，错过的日期不会补做旧批次，仅按当天近7天范围处理。

## 兼容与资源

0.5.0 引入的迁移首次把订阅调整为仅 JACS，只执行一次；0.5.1 不重新调整已完成迁移的用户订阅。其他来源历史文章、已读、收藏、密钥、旧总结和音乐数据保留。旧总结缺少译文时只补齐缺失字段；原文确有修订或服务／模型变化才将受影响内容标为待更新，成功前保留旧结果。

订阅两小时检查一次，最多两路来源请求，AI单路。普通文章和详细用量记录保留90天，收藏长期保留。阅读未启用时不创建数据库或调度，关闭阅读页面释放文章控件。没有全文下载、PDF解析或阅读工作进程。

0.5.1 为界面调整，本轮没有发出真实 AI 生成请求，也未重新评价翻译质量。历史服务测试见对应版本报告，当前界面检查见 [0.5.1 验证记录](validation-v051.md)。
