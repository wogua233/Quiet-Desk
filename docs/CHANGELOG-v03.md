# 静隅 0.3 更新说明

本次保留原有 18 种离线声音、收藏、场景、音量、桌面位置和专注统计。

## 这次可以直接试的地方

1. 在“在线电台 → 国内直连”选择一台。底部“暂停电台”只停止电台；“全部暂停”控制整个播放器。先单独暂停电台，再全部暂停/恢复，电台保持单独暂停。
2. 在设置里选择声音输出设备。选择会应用于环境声、在线直播、本地音乐和轻音效；不需要修改 Windows 的全局默认设备。
3. 试听轻音效可以在全部暂停时使用。总音量为零时会提示解除静音，轻音效选项默认仍关闭。
4. 桌面组件可从空白处拖动，也可以在按钮或滑块上静止按住约四分之一秒再拖整卡；直接滑动滑块仍是调音量。
5. 把组件拖到屏幕左侧或右侧，离开后收成细把手，鼠标悬停展开。锁定只禁止移动，不禁止播放操作。
6. 中性灰渐变与粉色强调替换原墨绿；背景默认 88% 不透明，文字不随之变淡。透明合成不支持时自动回退不透明外观。

## 验收边界

国内 6 个源在本机无应用代理请求下解码通过，不代表全国网络均可用，也不能排除系统 VPN 隧道路由。性能按十分钟单路与十分钟四路测量，每组另预热一分钟；不再要求两小时，也不将短测称作两小时通过。

详细数据与仍需实机操作的项目请看 validation-v03.md。许可见 SOUND-LICENSES.md 与 FFMPEG.md。
