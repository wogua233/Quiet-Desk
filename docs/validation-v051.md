# 静隅 0.5.1 阅读布局验证

日期：2026-09-14。Windows 本机，.NET SDK 10.0.401，Release / win-x64 自包含发布。

## 本轮修改

- 将阅读导航、刊物选择、筛选、刷新和队列入口合并为紧凑工具栏；窄窗口自动换行。
- 日期、时间依据、排序、收藏和未读放入按需打开的筛选浮层，应用后生效；取消及 Esc 放弃草稿。
- 阅读页隐藏整个底部播放器并减少内容边距，切换回音乐页面恢复底栏。没有修改音频状态或解码代码。
- 底部阅读状态合并为一行；完整队列状态与用量可通过悬停和 AI 队列菜单查看。宽窗口文章列表允许扩展至 520 DIP。
- 用户音乐数据、阅读订阅与 AI 缓存结构均未迁移。

## 已验证

| 检查 | 结果与范围 |
| --- | --- |
| Release 自包含发布 | 成功，无编译警告或错误 |
| 既有阅读回归检查 | 72 项 PASS，无 FAIL；见 reading-tests 原始记录 |
| 布局渲染 | 760×560、520×560 阅读视图，100%、125%、150%、200% 渲染；文章区域扩大，窄视图能显示列表，工具栏可换行。这是离屏布局检查，不代表实际切换系统 DPI 已测 |
| 本机实际窗口 | 鼠标进入阅读页，底栏消失；Ctrl+1 切回声音场景，底栏恢复；Ctrl+5 回阅读再次收起 |
| 筛选实际交互 | 展开排序下拉，选择更老在前后应用；列表从 9 月 13 日文章切至 9 月 12 日。恢复更新在前后列表顺序恢复 |
| 放弃草稿与焦点 | 勾选收藏但不应用，Esc 关闭后列表仍有 16 篇；重新打开收藏未勾选，焦点返回筛选按钮 |
| 队列菜单 | 实机发现 MenuItem 样式被错误用于 Separator，已限定样式作用类型并修复；重建后正常展开，未点击开始或发起 AI 请求 |

## 未验证及限制

本轮未重新进行收费 AI 生成、真实翻译质量审查、音频听感测试或长时间性能测试。没有把窗口隐藏当成音频暂停；代码只改变可见性和边距。

未逐一实测不同显示器、全部系统 DPI、屏幕阅读器或正在播放时的页面切换。既有音乐性能基线沿用历史报告。本轮未修改来源和队列调度逻辑。

## 复现

```powershell
./scripts/build.ps1 -Publish
./artifacts/QuietDesk-v0.5.1-win-x64/QuietDesk.exe --reading-test --out D:/Games/music/artifacts/v051/reading-tests.txt
./scripts/package.ps1
```

便携包：`artifacts/QuietDesk-win-x64.zip`；源码包：`artifacts/QuietDesk-source.zip`。包内不包含用户数据库、密钥或配置。
