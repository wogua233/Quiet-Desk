# 静隅 0.3 修订架构

## 播放状态

环境声与媒体共享 MixBus / WASAPI 输出。`Playing` 是总播放开关，`mediaPaused` 是媒体独立暂停标记。总暂停不清除独立暂停标记。直播暂停淡出后 Dispose MediaSession，释放网络和有界环形缓冲；继续重新连接。文件暂停关闭 ReadMedia，保留解码环形缓冲与原播放位置。

每次媒体选择递增 sourceVersion，并取消此前连接。连接成功后再次核对版本，过期结果立即回收。流有有限重试；媒体失败不关闭环境声。FFmpeg 子进程只用于 HLS/AAC，输出固定 44100Hz 双声道 float PCM；主进程环形缓冲最多三秒，管道与读取块有界。

## 设备与交互音

设备选择保存 endpoint ID，默认项为 null。变化时淡出、销毁旧 WASAPI、重建选定输出，再按原总状态恢复。启动或设备移除发现 ID 不可用时回退默认。轻音效是短寿命 WASAPI 输出，使用同一 endpoint ID 和总音量，由 SemaphoreSlim 限制为单个活动音效；暂停时可主动试听，播放完释放。

## 桌面宿主

DesktopHost 封装 HwndSource 真正桌面子窗口。Windows 10/11 兼容 manifest 允许子窗口透明合成；背景渐变透明、文本与控件不透明，不采样壁纸、不使用模糊。创建透明窗口异常则使用不透明渐变，并禁用透明设置。

空白拖动检查系统阈值；控件静止按住 250ms 后捕获到卡片，取消原控件点击；滑块立即移动保留正常行为。贴边后实际窗口改为 8×64 DIP，避免留下透明命中区域。展开为 220 DIP 宽；250ms 悬停展开，800ms 离开收起，拖动、按键和菜单期间不收起。位置按当前屏幕工作区回收。Explorer / DPI / 显示器变化的恢复封装在宿主，实际验收与代码覆盖分别记录。

## 存储与诊断

沿用 LocalApplicationData/QuietDesk，版本 3 设置保留原字段。新增设备 ID、透明度；placement 增加 edge，保留 x/y/locked。默认不开机运行、不自动出声，音效默认关。

性能采样仅在显式 acceptance-run 中开启，正式运行无采样；统计主进程和本应用登记的解码子进程，不扫描无关进程。1 秒采样，预热 60 秒后统计 600 秒。创建再隐藏主窗口，保留真实桌面和托盘，用静音输出避免打扰；不跳过读取或混音。短测不证明两小时稳定性。
