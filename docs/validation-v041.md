# 0.4.1 摘要阅读改版验证

日期：2026-09-14。功能从全文精读收敛为摘要／导读总结，采用文章列表和正文布局。
本报告区分自动化验证、离屏布局检查和待实机项。

## 构建与回归
- Windows x64 .NET 10 自包含发布。
- 阅读测试 26 项、音频信号 8 项、场景 7 项、基础验证 29 项通过，总计 70 项。
- 阅读覆盖：RSS／Atom、去重、日期、XML安全、密钥保护、每日10次及跨日、额度一次迁移、旧总结复用、并发生成只请求一次、收藏／已读筛选、全文任务和缓存清理、原始PDF保留、限流无连续重试。
- 新版程序集无 ReadingWorker，发布依赖已移除 PdfPig。验证截断APS导读、作者字段及仅包含全文content的订阅不会当成足够摘要。
- 音频测试保留真实字节／浮点适配器回归，未改动此前嗡嗡声修复。

## 来源
公开订阅实测11/12可获取并解析，JACS请求仍失败；详细条目数见 reading-sources-v041.json。
Nature系列订阅未给出摘要，Science部分记录仅有卷期信息，APS部分摘要被截断。能解析目录不代表摘要可用，也不代表今日没有文章。
新版会尝试补充官方公开摘要及Crossref摘要；仍不足则不生成总结。无机构全文获取，不读取浏览器Cookie。
来源表记录采样时的原始摘要长度；随后已增加APS作者／卷期清理和截断判断，并由固定样例回归验证。

## 界面
已生成并检查760×560 DIP双栏、520×560 DIP窄屏，以及100%、125%、150%、200%离屏渲染图。
修正了日期框截断、正文输入边框、白色密码框、设置保存按钮不易找到的问题。
离屏图只能证明布局渲染，不能替代真实鼠标、键盘、焦点、系统DPI和桌面操作验收；这些仍需试用确认。
主阅读页支持可见的收藏、原文和生成操作，订阅支持搜索，正文可复制；窄屏返回保留列表位置。
