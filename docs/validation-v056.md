# 静隅 0.5.6 验证记录

日期：2026-09-14。环境：本机 Windows x64、.NET 10 自包含发布。此次不进行两小时长测，不调用付费 AI，不读取或复制用户的 API 配置。音乐、阅读历史数据保持原有存储方式。

## 本轮变化

- 内置直连目录从 6 项扩充至 12 项，新增爵士、古典、流行入口；名称和风格均可搜索，无需先请求 Radio Browser。
- 新用户默认开启轻音效；旧配置在首次升级时开启一次，之后用户关闭的选择仍会保存。没有改变总静音、不自动播放等规则。
- 桌面组件采用辉光管风格的琥珀色计时，保留 220×320 DIP、真正桌面嵌入和原有交互。采用静态矢量笔画，不添加独立刷新计时器、模糊滤镜或持续动画。
- 波函数图标为原创高分辨率矢量及多尺寸 ICO；新增简体中文、当前用户安装向导。

## 实际电台验证

最终交付的 12 项全部通过本机应用播放路径的无代理连接和实际 PCM 解码，详情见 [直连目录](RADIO-DIRECT.md) 与 [逐项结果](validation-v056-radio.json)。不是仅验证 HTTP 200，也不是只用外部播放器验证。测试读取约 3 秒音频，记录非零峰值；结果中的 seconds 包含打开及解码时间，不代表长时间收听。

舒缓爵士新增 **101 Smooth Jazz** 和 **0N · Smooth Jazz**。两台是境外电台，保留美国／德国标识；本机对其流地址查询到 WLAN 路由，并通过禁用应用代理的实际解码。不同地区、运营商、未来源变化仍可能影响连接，不能保证全国网络均可用。没有更改 VPN 设置；测试不证明没有网络设备层面的其他转发。

候选源中，河南爵士 FM 在应用 HLS 测试失败，SomaFM Sonic Universe 连接失败，湖南音乐之声出现 ACM 解码失败，均从本版目录排除。外部 FFmpeg 能解码不等同于应用可播放，因此以最终应用路径结果为准。未逐段人工试听完整节目，不保证任意时段无广告、主持或节目风格变化。

## 安装、升级与卸载

采用 NSIS 3.12 便携编译器，不在用户电脑安装开发工具。隔离 QA 使用相同脚本、相同发布负载和不同的注册项／快捷方式名称，仅跳过“应用运行中”拦截，以免打断原有试用程序。

- 静默安装成功；覆盖升级退出码 0，注册版本为 0.5.6，卸载命令正确引用实际路径。
- QA 负载 644 个文件逐一 SHA256 校验，0 个不一致；最终包额外加入本报告、许可及通过记录，不改变已验证程序二进制。
- 桌面和开始菜单快捷方式均创建成功；安装后的程序通过 10 项检查。
- 静默卸载退出码 0，已知程序文件、快捷方式及 QA 卸载注册项均删除。
- 特意放入安装目录的未知文件在升级和卸载后均保留。卸载脚本只删除清单文件，不递归清空目录，不触碰 `%LOCALAPPDATA%\QuietDesk`。
- 中文向导的实际人工逐页点击尚未验证；测试涵盖静默安装执行路径。没有商业代码签名，不要求用户关闭系统防护。

## 凭据与交付边界

发布、便携包和源码暂存区均执行失败即停止的凭据／用户数据检查，检查包括文本及程序集中的常见密钥样式、UTF-16 字符串、非空 DPAPI 字段、数据库、配置和日志文件。扫描器只输出路径和原因，不打印匹配值。

本轮还检查了既有 Git 历史中的 299 个唯一文本对象，未发现匹配；新增源码和最终发布负载另行扫描。正则扫描不能构成对任意未知凭据格式的绝对证明，但本轮从未将本机服务配置加入构建目录，也没有将测试密钥写入代码、报告或打包脚本。

安装器携带 .NET 运行库、18 种离线声音、解码器和已有许可；NSIS 许可及新图标说明随包提供。卸载保留用户数据，旧电脑中加密的密钥不会随安装包转移到新电脑。
