# 静隅 0.2 验收记录

更新：2026-09-12T00:05:36（本机时间）

## 构建与功能

Windows build 26200 x64，.NET SDK 10.0.401 / 运行时 10.0.12，NAudio 2.2.1。Release 自包含 x64 构建通过，零警告、零错误。

自动验证：**40 项通过，0 项失败**。原始输出见 `evidence-v02/verification.txt` 和 `evidence-v02/model-verification.txt`。

覆盖 18 种 PCM 解码与循环接缝、四路混音不削波、按需打开和淡出释放、最多四个环境声读取器、三秒网络缓冲、取消读取、MP3/FLAC 解码、计时暂停/跨日/睡眠间隔、设置恢复、无自动播放、组合重命名/删除/撤销、队列排序及静音恢复。

## 界面

- 温润深色公共控件、矢量图标、音量百分比、键盘焦点和小窗口换列已实现。
- WPF 离屏渲染覆盖 100%、125%、150%、200% 及 760 DIP 宽小布局；预览位于 `evidence-v02/layout-*.png` 和 `evidence-v02/main-preview.png`。
- 离屏渲染用于检查布局、文字与绘制，不等同于实际切换系统 DPI、键盘导航或鼠标命中测试。
- 新版已在实际桌面创建 `SHELLDLL_DefView` 子窗口，DPI 120；桌面诊断日志保存在用户应用数据中，不打包个人日志。
- Windows computer-use 工具两次初始化均返回“failed to write kernel assets: 系统找不到指定的路径”。因此本轮真实鼠标操作、窗口截图与键盘导航未标记通过；不使用替代 UI 自动化绕过该故障。

## 音频与来源

18 种声音全部随包离线提供。时长、SHA256、峰值与接缝指标见 `sound-validation-v02.json`；许可证见 `SOUND-LICENSES.md`，下载来源与校验见 `expanded-source-manifest.json`。

真实录音采用交叉淡化、峰值限制和按素材需要的滤波。白/粉红/棕噪声由固定种子生成。窗边雨为雨声的滤波版本；风扇原始素材较短，经无缝处理后重复。图书馆录音为 CC BY-NC 4.0，仅限非商业使用。

数值接缝检查不等同于人耳主观验收。逐项听感、是否疲劳、生活空间语音可辨识度及耳机/音箱体验仍需用户试听反馈。本机没有声学录音或主观听觉评审证据，不声称这些项目已通过。

CPU 以逻辑处理器数归一化。MiB 为 1024² 字节；目标仍为单路私有工作集 ≤150 MB、平均整机 CPU ≤1%。原始记录保留所有采样，不剔除峰值。用户要求停止两小时长测，已有单路十分钟与四路约十分钟保留为短测；不记为两小时通过。
