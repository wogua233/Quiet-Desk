# 静隅 0.3.3：共用输出失真修复

用户反馈：扬声器下，调高软件总音量会产生明显嗡嗡声；仅提高系统音量不会，全部暂停后消失，其他播放器正常。

排查确认混音末端持续应用 x/(1+abs(x))，即使信号未超限也改变波形。幅度 0.8、1kHz 正弦按原公式计算的 THD+N 约 9.549134%。此行为可造成随软件音量增大的谐波失真，但不能仅凭离线测试确认用户现场嗡嗡声的全部来源。

修复：移除持续波形压缩，使用双声道联动的前瞻峰值保护。正常范围内样本保持原值；固定延迟 256 帧（44.1kHz 下约 5.8ms），仅峰值超过 0.98 时衰减，约 80ms 释放。数组和峰值队列大小固定，无频率滤波，不删除自然声的低频内容。

39 项自动检查通过：新增四项信号测试、29 项原有离线／混音检查、六项播放控制检查。完整混音器在总音量与媒体音量均为 100% 时，1kHz 正弦 THD+N 约 0.000004%；正常范围逐采样一致（除固定延迟），静音严格为零，过载与瞬态峰值 ≤0.98，左右声道比例保持，结果不依赖读取块大小。原始结果见 evidence-v033。

验证均采用内存信号处理，没有向扬声器播放高音量测试音。本轮未重跑二十分钟性能测试，未录制设备输出，用户现场听感仍需新版试听确认。旧验证报告中的性能数据仅对应其原版本。

退出托盘中的旧版后运行 0.3.3，设置、组合和收藏保留。移除原压缩后同一滑块位置可能更响，请先从较低音量试听；若嗡嗡声仍存在，需要继续对具体电台／声音和实际输出录音排查。
