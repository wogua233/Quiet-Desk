# 双语提示词、缓存与用量

提示词版本：`bilingual-v1`，实现位于 `src/QuietDesk/Reading/ReadingAiPolicy.cs`。目标语言固定 `zh-CN`。

参考本机 `bilingual-paper` skill 的双语分区与原始符号保留原则，仅将适用的短规则整理到项目。没有引入 PDF、浏览器、OCR 或全文流程，也不在每个请求中附带整份 skill。规则本身不保证固定比例的 token 节省。

每篇通常一次 Chat Completions 请求，JSON字段为 `ChineseTitle`、`ChineseAbstract`、`ChineseSummary`。只请求缺失字段，英文原文直接使用数据库内容，不要求模型重复输出。摘要不足只请求标题。模型输出必须是完整 JSON、正常 finish_reason、具备所需非空中文字段，异常或截断不能标记完成。

研究摘要仅概括原文问题、发现与意义；新闻区分事实和观点。翻译保留数字、化学式、单位、符号和限定语，不补写方法、局限或全文结论。正文以独立JSON资料字段输入，明确视为不可信文献，不能执行其指令；请求无工具定义。

缓存分别绑定文章标题/摘要内容哈希，以及服务地址、模型、语言与提示词版本。旧总结允许补齐译文，避免升级时批量重新总结。记录独立 feed 哈希，重复出现相同订阅导读不会覆盖后续补充的摘要。真实修订保留旧展示，待新结果校验成功后替换。

后台云端单路。统计来自服务响应中的 prompt_tokens、completion_tokens、prompt_cache_hit_tokens（兼容 prompt_tokens_details.cached_tokens）；缺失值保留未知。本次真实生成请求为0，因此没有真实 token 用量或服务缓存命中率可以报告。

HTTPS 使用系统代理、系统TLS与证书验证，优先HTTP/2并允许服务协商较低协议；不关闭证书验证。本机无认证协议对照曾获得HTTP/2的401响应，但真实模型目录连接仍中断，尚未确认该密钥下的可用模型，不宣称已验证Flash可用。

真实测试入口 `--ai-live-test` 与应用调度隔离：读取单独DPAPI加密配置，在发送前持久化次数，最多3次生成，有既存次数文件时拒绝再次运行，首个错误后停止，finally删除临时配置。此次没有把测试密钥保存至用户正式配置、源码、日志或发布包。
