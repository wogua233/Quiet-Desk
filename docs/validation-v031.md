# 静隅 0.3.1：个人组合可见性修复

问题：声音场景页只构造了四个内置预设，保存的个人组合仅出现在“我的收藏”，导致在原页面看不到刚保存的组合。

修复：声音场景页增加“我的组合”区域，监听组合集合变化，局部更新可选按钮。保存、覆盖、重命名、删除和撤销立即生效，不重建整页，保留搜索与滚动状态。原有组合自动显示，无需重新保存；数据格式不变。

验证：Release 自包含构建成功；六项专门回归通过，另十一项既有模型与布局检查通过。覆盖新组合立即出现、点击恢复声道与音量、不自动播放、覆盖不重复、重命名/删除/撤销、缓存页面切换、重启恢复。原始输出及布局图见 evidence-v031。既有模型测试首次因新输出目录缺少 FLAC 测试夹具失败，补齐原测试夹具后通过。

本轮没有重跑性能长测；validation-v03.md 中的数据对应 0.3 发布版。本次未改变音频引擎和桌面宿主。实际鼠标对话框操作未在本轮重新验收，自动测试直接调用保存入口并触发对应的 WPF 选择按钮。

更新方式：退出托盘中的旧版，再运行新版 QuietDesk.exe；保留 %LOCALAPPDATA%/QuietDesk 中的原用户数据。
