# 0.3 实机复核清单

此表为仍需操作的验收说明，不表示这些项目已通过。建议先将总音量调低。测试后可恢复原音量；不用重置或删除用户数据。

| 操作 | 预期结果 |
|---|---|
| 开启细雨并播放国内电台，点击“暂停电台” | 细雨继续；电台停止，按钮改为继续电台 |
| 电台单独暂停后，全部暂停再恢复 | 细雨恢复，电台继续保持单独暂停 |
| 继续电台 | 重新连接当前直播，而不是播放暂停时缓存 |
| 本地音乐单独暂停后继续 | 从原位置附近继续；不重新从曲首开始 |
| 暂停所有播放，切换输出设备 | 保持安静；主动试听在所选设备发声 |
| 拔掉选中的耳机，再播放／查看提示 | 回退系统默认设备并说明，暂停时不自行出声 |
| 在桌面组件空白处拖动 | 整张卡片随拖动移动 |
| 单击组件按钮、直接拖音量滑块 | 按钮执行一次；滑块只调音量，不移动卡片 |
| 静止按住按钮或滑块约 250ms，再拖动 | 进入整卡拖动，松开不额外执行按钮点击 |
| 将组件拖到左／右屏幕边缘，鼠标离开 | 约 800ms 后只剩窄把手；原卡片区域可操作桌面 |
| 悬停把手 | 约 250ms 展开；操作控件期间不会收起 |
| 锁定位置后拖动 | 不移动，正常按钮和音量操作仍可用 |
| 调低背景不透明度 | 仅背景变淡，文字和按钮清晰；没有黑块和残影 |
| Win+D、窗口遮挡、锁屏解锁、Explorer 重启 | 保持桌面层级或自动恢复，不变成总在最前的悬浮窗 |
| 不同 DPI 屏幕之间移动、移除原显示器 | 组件回到可用工作区，按钮文字和把手尺寸正常 |

请按实际观察记录版本、Windows 构建、缩放、输出设备、步骤与结果。切换 VPN、Explorer 重启和显示器拔插会影响当前工作，应在方便时操作；程序不会为测试主动修改这些系统状态。
